# Vocab Garden V1

Prototype học từ vựng theo phong cách pastel / spreadsheet tracker.

## Tính năng hiện tại
- Dashboard tuần/tháng
- Vocab List + tìm kiếm + lọc
- Thêm từ mới
- Phát âm bằng Web Speech API của trình duyệt
- Random Vocab Test 5 câu
- Mastery cập nhật theo kết quả test
- Kanban New / Learning / Mastered
- Lưu dữ liệu vào localStorage
- Responsive cho desktop/mobile

## Chạy local
```bash
npm install
npm run dev
```
Mở http://localhost:3000

## Deploy Vercel
1. Push thư mục này lên GitHub.
2. Import repository vào Vercel.
3. Framework preset: Next.js.
4. Deploy.
